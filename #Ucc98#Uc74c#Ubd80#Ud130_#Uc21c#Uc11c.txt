처음부터 올리는 순서

1. 이 ZIP을 다운로드합니다.
2. ZIP을 마우스 오른쪽 클릭하고 '모두 압축 풀기'를 누릅니다.
3. GitHub에서 새 저장소를 만듭니다.
4. Add file → Upload files를 누릅니다.
5. 압축을 푼 폴더 안의 모든 파일과 폴더를 드래그해서 올립니다.
6. Commit changes를 누릅니다.
7. 업로드가 끝난 뒤 Add file → Create new file을 누릅니다.
8. 파일 이름에 .github/workflows/daily.yml 을 입력합니다.
9. DAILY_WORKFLOW_COPY.txt의 내용을 복사해서 붙여넣습니다.
10. Commit changes를 누릅니다.

이 ZIP에는 점(.)으로 시작하는 폴더나 파일이 없습니다.
