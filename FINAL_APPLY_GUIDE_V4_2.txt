KOREA ENGINE V4.2 적용 순서

1. 이 ZIP의 `korea-rate-fx-engine-main` 내부 파일을 GitHub 저장소 루트에 그대로 덮어쓴다.
2. 특히 아래 파일이 반드시 교체되었는지 확인한다.
   - src/collectors/global_market.py
   - src/collectors/ecos.py
   - src/core/ecos_resolver.py
   - config/ecos_series.json
   - config/settings.json
   - .github/workflows/daily.yml
3. GitHub Actions → Korea Rate FX Engine → Run workflow 한 번 실행한다.
4. 다음 로그를 확인한다.
   - ECOS 지표: mode=incremental 표시
   - fx_reserves: table=732Y001 item=합계
   - GLOBAL_MARKET: `FRED batch` 한 번만 표시
   - FRED 장애 시에도 11개 개별 25초 재시도가 없어야 함
5. 실행 완료 후 output/korea_fx_forecast_v2.json에서
   - forecast_operational=true
   - forecast_path 1/3/6/12개월 존재
   - prediction_status=forecast
   를 확인한다.

중요:
- KRX collector의 `not_configured`는 승인형 선물/국채 API 설정이 꺼져 있다는 뜻이며,
  별도로 실행되는 pykrx 인증 기반 KOSPI200/KOSDAQ150 수집과는 다른 모듈이다.
- REB `not_configured` 역시 현재 금리/환율/원화유동성 연속예측의 차단조건이 아니다.
